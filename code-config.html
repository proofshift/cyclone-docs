Configuration

Set current limits and neutral behavior, check configuration results, and save supported settings.

Set current limits explicitly

Java
CurrentLimitsConfigs limits = new CurrentLimitsConfigs()
    .withStatorCurrentLimit(30)
    .withSupplyCurrentLimit(20);
StatusCode result = motor.getConfigurator().apply(limits);
if (!result.isOK()) {
    System.err.println(result.describe());
}
FieldUnitAccepted team range
StatorCurrentLimitA1–95
SupplyCurrentLimitA1–40

Unset fields are left alone. Do not set unsupported fields merely because a class contains them. In particular, the configurable lower supply-current limit and lower-time fields are refused by this library.

What survives a restart?

SettingPersistence / action
Current limitsApply the limits and check the result. After saving and restarting, check the values reported by the motor rather than assuming they were restored.
Velocity gainsSet with setVelocityGain(); saveConfiguration() persists the supported gain fields.
Coast / Brake neutral modeResets when the motor restarts. Set it again at startup; Save does not keep this setting.
Mechanism ratio and wrapStored in your robot program, not on the motor. Set it again when the program starts.
Software limitsThe public configurator refuses them. Implement mechanism travel limits and homing in your robot code.
Java
// Call after intentionally configuring a stopped controller.
// Do not write flash from a periodic control loop.
motor.saveConfiguration();

Choose neutral behavior

Neutral behavior determines what happens when the controller applies no driving output. Coast lets the shaft turn freely. Brake electrically resists rotation, but does not hold a commanded position or replace a mechanical brake. Its braking current is not adjustable through this API.

Java
StatusCode result = motor.setNeutralMode(SwyftCyclone.NeutralMode.BRAKE);
if (!result.isOK()) System.err.println(result.describe());

Handling a configuration failure

Range errors, unsupported fields and setting changes attempted while the motor is enabled are different problems. Print StatusCode.describe(), stop the motor when requested, and retry only the intended setting. Read back or inspect the live result before relying on it.
