Feature guide

Each feature, what it does, and how to call it. Full signatures on the API reference.

Output

Command duty every loop; sign is direction. Duty is a fraction of the bus, not of free speed — 0.5 is half the bus voltage, and a value past the range clamps to full output. The stator limit does not govern duty.

Current limits

setTeamLimits(warnC, tripC, statorA) writes the temperature warning, the temperature trip, and the stator limit together; setStatorCurrentLimit(a) writes the stator limit alone. Ranges: warning 40–80 °C, trip up to 80 °C, stator 1–160 A. Set the supply limit in SWYFT Link. How the limits work

Neutral mode

The Cyclone coasts when uncommanded. setNeutralMode(NeutralMode.COAST) succeeds; BRAKE throws, and isBrakeModeSupported() is false. Design for coast — holding current, or a mechanical brake on an elevator.

Telemetry

getLatest() returns a coherent snapshot; the same values are on individual getters. isAlive(0.1) is false when no frame has arrived in 100 ms — otherwise an unplugged motor reads like a stopped one.

LEDs

User lights are 1–5, left to right; the status lights cannot be set. Channels are 0–255; the motor caps the brightest channel and scales the rest. Setting all five to black hands them back to the controller — clearLEDs() is the off path. Status lights

Java
import com.swyftrobotics.cyclone.v4.LedAnimation;

motor.setLEDs(0, 120, 255);                            // all five
motor.setLED(3, 255, 0, 0);                            // centre light
motor.setLEDs(255, 40, 0, LedAnimation.ChaseForward);  // one animation
motor.clearLEDs();                                     // off
