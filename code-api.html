API reference

The public methods of com.swyftrobotics.cyclone.v4.SwyftCyclone. Worked examples are in the Feature guide.

Note

Methods marked Under construction compile and transmit but the motor does not act on them yet.

Construction

SignatureDescription
SwyftCyclone(int deviceNumber)Construct on the default CAN bus.
SwyftCyclone(int deviceNumber, int canBus)Construct on a specific CAN bus.
int getDeviceNumber()The device number (CAN ID), 1–62.

Output

SignatureDescription
void set(double duty) / void setDutyCycle(double duty)Duty cycle, −1 to 1. Command every loop.
void setCurrent(double amps)Torque current. Under construction
void setVelocity(double rpm)Closed-loop speed. Under construction
void setPosition(double rad)Closed-loop position. Under construction
void disable()Coast and drop the setpoint.

Configuration

SignatureDescription
void setTeamLimits(double warnC, double tripC, double statorA)Temperature warning and trip, and stator limit.
void setStatorCurrentLimit(double amps)Stator limit alone, 1–160 A.
void setNeutralMode(NeutralMode mode)COAST succeeds; BRAKE throws.
boolean isBrakeModeSupported()False.
void saveConfiguration()Persist device config across power loss.

Faults and e-stop

SignatureDescription
void estop()Latching kill; coasts.
void releaseEstop()Clear the e-stop latch.
void clearFaults()Refused while the cause is present.
boolean hasHardFault()True while a hard fault is latched.

Telemetry

SignatureDescription
SwyftCycloneData getLatest()A coherent snapshot of all telemetry.
boolean isAlive(double maxAgeSec)False if no frame arrived within the age.
double getVelocityRpm()Mechanical RPM.
double getSupplyCurrent()Bus amperes.
double getSupplyVoltage()Bus volts.
double getDeviceTemp()Board temperature, °C.

LEDs and identify

SignatureDescription
void setLEDs(int r, int g, int b)All five user lights, channels 0–255.
void setLEDs(int r, int g, int b, LedAnimation a)All five with an animation.
void setLED(int index, int r, int g, int b)One user light, index 1–5.
void clearLEDs()Turn the user lights off.
void identify()Flash the status lights white to locate the motor.
