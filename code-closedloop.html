Closed-loop control

Tune the velocity and position loops so a Cyclone holds a setpoint under load.

Velocity, position, and current commands close their loop on the controller, at the motor. The loop compares the setpoint to the encoder and adjusts output to close the gap. Each mechanism needs gains that match its inertia and load; the defaults are a starting point, not a final answer. This page sets the velocity and position gains and walks through tuning one mechanism.

Set velocity gains

The velocity loop is a PI controller. kP reacts to the present speed error; kI removes the small steady error kP alone leaves behind. Apply them through Slot0Configs.

Java
import com.swyftrobotics.cyclone.v4.Slot0Configs;

var gains = new Slot0Configs();
gains.kP = 0.0008;   // output per unit of speed error
gains.kI = 0.004;    // removes steady-state error
shooter.getConfigurator().apply(gains);
shooter.saveConfiguration();   // keep the gains across a power cycle

Tune a velocity loop

Tune one mechanism at a time, on the real robot, with the mechanism under its normal load.

  1. Start from the defaults. Command a mid-range speed with setVelocity and watch the measured speed with getVelocityRpm.
  2. Raise kP until the motor reaches speed quickly. If it oscillates around the target, kP is too high — lower it until the wobble stops.
  3. If the motor holds a speed slightly below the target, raise kI in small steps until the error closes. Too much kI makes it overshoot then swing back.
  4. Test at the speeds you actually use, and under the load the mechanism sees in a match. Save when it holds.
Tip

A value outside its range is refused, not clamped, and apply returns the failing StatusCode. Check isOK() while tuning so a rejected gain does not look like a bad tune.

Set the position gain

Position mode runs a proportional loop whose output is a velocity request into the velocity loop above. Tune the velocity loop first, then set the position gain PositionKP through ClosedLoopGeneralConfigs.

Java
import com.swyftrobotics.cyclone.v4.ClosedLoopGeneralConfigs;

var pos = new ClosedLoopGeneralConfigs();
pos.PositionKP = 2.0;   // 0–5.0; higher drives to target faster
arm.getConfigurator().apply(pos);

Full example — a velocity subsystem

A complete command-based subsystem that configures a shooter, holds a speed, and reports when it is up to speed.

ShooterSubsystem.java
import com.swyftrobotics.cyclone.v4.SwyftCyclone;
import com.swyftrobotics.cyclone.v4.Slot0Configs;
import edu.wpi.first.wpilibj2.command.SubsystemBase;

public class ShooterSubsystem extends SubsystemBase {
    private final SwyftCyclone motor = new SwyftCyclone(9);
    private double targetRpm = 0;

    public ShooterSubsystem() {
        // current limits protect the motor; gains make it hold speed
        motor.setTeamLimits(75, 85, 60);

        var gains = new Slot0Configs();
        gains.kP = 0.0008;
        gains.kI = 0.004;
        motor.getConfigurator().apply(gains);
        motor.saveConfiguration();
    }

    /** Command a flywheel speed in RPM. */
    public void setSpeed(double rpm) {
        targetRpm = rpm;
        motor.setVelocity(rpm);
    }

    public void stop() {
        targetRpm = 0;
        motor.disable();
    }

    /** True once the flywheel is within 100 RPM of target. */
    public boolean atSpeed() {
        return Math.abs(motor.getVelocityRpm() - targetRpm) < 100;
    }
}
