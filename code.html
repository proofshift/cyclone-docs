Setup & install

Install the Java library, configure a Cyclone, and command it from your robot program.

Install the vendor library

These examples use Cyclone Java library 0.28.0 and the SystemCore WPILib 2027 API. Check the version in your project’s Cyclone vendordep before using them.

In WPILib, open Manage Vendor Libraries, choose Install new libraries (online), and enter this URL:

https://cyclone.docs.swyftrobotics.com/files/vendor-lib/2027/SwyftCycloneV4.json

You can also open the installer JSON to check its version. It selects 0.28.0 for the SystemCore WPILib 2027 API. Keep one Cyclone library version in the project and build before deploying. Java imports use com.swyftrobotics.cyclone.v4.

A complete first program

This example uses device 1 and repeats a 10% duty request while teleop is enabled. The 30 A stator and 20 A supply limits illustrate the configuration calls. Choose limits for your mechanism and check that the device accepted them. Keep the mechanism’s travel clear before enabling.

Java · Robot.java
package frc.robot;

import org.wpilib.framework.TimedRobot;
import com.swyftrobotics.cyclone.v4.CurrentLimitsConfigs;
import com.swyftrobotics.cyclone.v4.StatusCode;
import com.swyftrobotics.cyclone.v4.SwyftCyclone;

public class Robot extends TimedRobot {
    private final SwyftCyclone motor = new SwyftCyclone(1);
    private boolean configured;

    public Robot() {
        CurrentLimitsConfigs limits = new CurrentLimitsConfigs()
            .withStatorCurrentLimit(30)
            .withSupplyCurrentLimit(20);
        StatusCode result = motor.getConfigurator().apply(limits);
        configured = result.isOK();
        if (!configured) System.err.println(result.describe());
    }

    @Override
    public void teleopPeriodic() {
        if (configured) motor.setDutyCycle(0.10);
        else motor.disable();
    }

    @Override
    public void disabledInit() {
        motor.disable();
    }

    @Override
    public void close() {
        motor.close();
        super.close();
    }
}

Create the motor once

Create one SwyftCyclone object for each motor when your robot program starts. Keep using that object; do not create a new one every time the periodic code runs. The library sends an enable heartbeat, a repeated message confirming that control is active. Your code must also repeat the intended motor command. Call close() when the object will no longer be used.

Before enabling

  • Give the device a unique number and verify the CAN bus connection.
  • Choose a consistent sign convention and a safe first test.
  • Read configuration failures instead of assuming that a write succeeded.
  • Keep the DriverStation gate in use. It cannot be disarmed through the public API.
