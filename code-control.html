Control requests

The four ways to command a Cyclone — duty, velocity, position, and current — plus follower and stop.

You drive a Cyclone by choosing a control mode and giving it a setpoint. Duty cycle is open-loop; velocity, position, and current are closed-loop and run on the controller. A setpoint is held for about 100 ms and then expires, so command the motor every loop — from teleopPeriodic or a subsystem periodic. Send NaN or infinity and the command is refused, not clamped.

Duty cycle

Duty cycle is a signed fraction of the bus voltage, −1 to +1. It is the direct, open-loop mode: 0.5 applies half the available voltage forward. Use it for hand-driven mechanisms and drivetrains.

Java
intake.setDutyCycle(operator.getRightY());   // -1 .. +1
intake.set(0.4);                             // set() is the same call

Velocity

Velocity mode holds a mechanical speed in RPM against changing load. The controller closes the loop with its velocity gains — see Closed-loop control.

Java
shooter.setVelocity(3000);   // hold 3000 RPM
shooter.setVelocity(0);      // hold zero — actively resists motion

Position

Position mode drives to a signed, multi-turn rotor angle in radians and holds it. Zero is where the rotor sat at power-on. For a geared mechanism, use the mechanism helpers so you can command output rotations instead of rotor radians.

Java
arm.setPosition(Math.PI / 2);   // quarter turn from power-on, and hold

Current

Current mode commands a signed torque current in amperes. Torque is proportional to current, so this mode sets force directly — useful for intakes that grip and for mechanisms held against a stop.

Java
roller.setCurrent(20);    // 20 A of forward torque
roller.setCurrent(-8);    // 8 A the other way

The stator current limit still caps this mode. A request above the limit is held at the limit.

Follower

A follower mirrors another Cyclone’s output, for the second motor on a shared mechanism. Give it the leader’s device number and whether it is mounted aligned with or opposed to the leader.

Java
import com.swyftrobotics.cyclone.v4.Follower;
import com.swyftrobotics.cyclone.v4.MotorAlignmentValue;

// leftFollower mirrors device 1, mounted the opposite way
leftFollower.setControl(new Follower(1, MotorAlignmentValue.Opposed));
leftFollower.stopFollowing();   // return to direct control

Stop

Two ways to stop: disable for the normal end of a command, and estop for an emergency.

Java
intake.disable();        // drop the setpoint and coast

intake.estop();          // latching kill — stays off until released
intake.releaseEstop();   // first step of re-arming
