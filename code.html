Setup & install

Add the vendor library and drive a motor in a few lines.

Before you start

A WPILib 2027 robot project, and a Cyclone with a device number assigned (1–62). Java only for now.

Install the vendor library

Add SwyftCycloneV4.json (library 0.25.0) to the project’s vendordeps/ folder and rebuild. The device class is com.swyftrobotics.cyclone.v4.SwyftCyclone.

Construct the motor

Construct with the device number you assigned in SWYFT Link. A second constructor, SwyftCyclone(id, canBus), selects the CAN bus.

Java
import com.swyftrobotics.cyclone.v4.SwyftCyclone;

private final SwyftCyclone intake = new SwyftCyclone(5);

Drive it

The Cyclone runs on duty cycle: a signed fraction of the bus, −1 to +1. Command it every loop — a setpoint older than 100 ms coasts. Set current limits once in robotInit().

Robot.java
@Override
public void robotInit() {
    intake.setTeamLimits(75, 85, 40);   // warn °C, trip °C, stator A
}

@Override
public void teleopPeriodic() {
    intake.setDutyCycle(operator.getRightY());   // every loop
}

@Override
public void disabledInit() {
    intake.disable();
}

Set the direction in SWYFT Link, not in the constructor. Orientation
