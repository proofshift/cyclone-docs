Setup & install

Add the vendor library and drive a motor in a few lines.

This page takes a robot project from no vendor library to a Cyclone spinning under joystick control. It assumes the motor is wired (Wiring) and has a device number set in SWYFT Link.

1. Install the vendor library

The Cyclone ships as a WPILib vendor dependency for the 2027 season.

  1. Download SwyftCycloneV4.json.
  2. Copy it into the robot project’s vendordeps/ folder.
  3. Rebuild the project so the build picks up the library.

The device class is com.swyftrobotics.cyclone.v4.SwyftCyclone. If the build cannot resolve it, confirm the .json is in vendordeps/ and rebuild.

2. Construct the motor

Create one SwyftCyclone per physical motor, with the device number you assigned in SWYFT Link. Construct it once, as a field — not inside a periodic method.

Java
import com.swyftrobotics.cyclone.v4.SwyftCyclone;

// device number 5, on the default CAN bus
private final SwyftCyclone intake = new SwyftCyclone(5);

// on a specific CAN bus:
// private final SwyftCyclone intake = new SwyftCyclone(5, 1);

3. Set current limits at start-up

Set current limits once, in robotInit(), before the motor is enabled. The limits protect the motor and the battery; size them for the mechanism, not at the ceiling. How the limits work

Java
@Override
public void robotInit() {
    intake.setTeamLimits(75, 85, 40);   // warn °C, trip °C, stator A
}

4. Drive it every loop

Command the Cyclone in one of four modes — duty, velocity, position, or current (Control requests). The example below uses duty cycle, a signed fraction of the bus from −1 to +1. A setpoint expires after about 100 ms, so command the motor every loop, and stop it when the robot is disabled.

Java
@Override
public void teleopPeriodic() {
    intake.setDutyCycle(operator.getRightY());   // -1 .. +1, every loop
}

@Override
public void disabledInit() {
    intake.disable();   // coast when disabled
}

Set the direction in SWYFT Link, not in the constructor. Orientation

Full first program

The three steps above, as one complete TimedRobot. Deploy this, enable in teleop, and the intake follows the operator’s right stick.

Robot.java
import com.swyftrobotics.cyclone.v4.SwyftCyclone;
import edu.wpi.first.wpilibj.TimedRobot;
import edu.wpi.first.wpilibj.XboxController;

public class Robot extends TimedRobot {
    private final SwyftCyclone intake = new SwyftCyclone(5);
    private final XboxController operator = new XboxController(0);

    @Override
    public void robotInit() {
        intake.setTeamLimits(75, 85, 40);   // warn °C, trip °C, stator A
    }

    @Override
    public void teleopPeriodic() {
        intake.setDutyCycle(operator.getRightY());
    }

    @Override
    public void disabledInit() {
        intake.disable();
    }
}
