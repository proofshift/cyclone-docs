API reference

Every public method of SwyftCyclone, grouped, with a short example for each. Task walk-throughs are in Control requests, Closed-loop control, and Status signals.

Construct

Create one SwyftCyclone per motor, with the device number you set in SWYFT Link.

Java
import com.swyftrobotics.cyclone.v4.SwyftCyclone;

private final SwyftCyclone intake = new SwyftCyclone(5);
// on a specific CAN bus:
// new SwyftCyclone(5, 1);
SignatureDescription
SwyftCyclone(int deviceNumber)Construct on the default CAN bus.
SwyftCyclone(int deviceNumber, int canBus)Construct on a specific CAN bus.
int getDeviceNumber()The device number (CAN ID), 1–62.

Command output

Pick the mode that matches the mechanism: duty for open-loop, or velocity, position, or current for closed-loop.

Java
intake.setDutyCycle(0.4);        // 40% of bus, forward
shooter.setVelocity(3000);       // hold 3000 RPM
arm.setPosition(Math.PI / 2);    // quarter turn
roller.setCurrent(20);           // 20 A of torque
intake.disable();                // coast
SignatureDescription
void set(double duty) / void setDutyCycle(double duty)Duty cycle, −1 to 1.
void setVelocity(double rpm)Closed-loop mechanical speed.
void setPosition(double rad)Closed-loop position.
void setCurrent(double amps)Torque current, signed.
void disable()Coast and drop the setpoint.

Configure

Set limits and neutral mode once at start-up, then save to keep them across a power cycle.

robotInit()
intake.setTeamLimits(75, 85, 40);   // warn °C, trip °C, stator A
intake.setNeutralMode(SwyftCyclone.NeutralMode.COAST);
intake.saveConfiguration();
SignatureDescription
void setTeamLimits(double warnC, double tripC, double statorA)Temperature warning and trip, and stator limit.
void setStatorCurrentLimit(double amps)Stator limit alone, 1–160 A.
void setNeutralMode(NeutralMode mode)COAST succeeds; BRAKE throws.
void saveConfiguration()Persist device config across power loss.

Faults and e-stop

Read faults, clear them once the cause is gone, and latch the motor off in an emergency.

Java
if (intake.hasHardFault()) {
    intake.clearFaults();        // refused while the cause is present
}
intake.estop();                  // latching kill
intake.releaseEstop();           // then re-arm
SignatureDescription
boolean hasHardFault()True while a hard fault is latched.
void clearFaults()Refused while the cause is present.
void estop()Latching kill; coasts.
void releaseEstop()Clear the e-stop latch.

Read telemetry

Check the motor is alive, then read a coherent snapshot or an individual value.

Java
if (intake.isAlive(0.1)) {
    double rpm  = intake.getVelocityRpm();
    double amps = intake.getSupplyCurrent();
    double temp = intake.getDeviceTemp();
}
SignatureDescription
SwyftCycloneData getLatest()A coherent snapshot of all telemetry.
boolean isAlive(double maxAgeSec)False if no frame arrived within the age.
double getVelocityRpm()Mechanical RPM.
double getSupplyCurrent()Bus amperes.
double getSupplyVoltage()Bus volts.
double getDeviceTemp()Board temperature, °C.

LEDs and identify

Set the middle five user lights, or flash the whole strip to find a motor.

Java
import com.swyftrobotics.cyclone.v4.LedAnimation;

intake.setLEDs(0, 120, 255);                            // all five
intake.setLED(3, 255, 0, 0);                            // centre
intake.setLEDs(255, 40, 0, LedAnimation.ChaseForward);  // animation
intake.clearLEDs();
intake.identify();                                      // locate it
SignatureDescription
void setLEDs(int r, int g, int b)All five user lights, channels 0–255.
void setLEDs(int r, int g, int b, LedAnimation a)All five with an animation.
void setLED(int index, int r, int g, int b)One user light, index 1–5.
void clearLEDs()Turn the user lights off.
void identify()Flash the status lights white to locate the motor.
