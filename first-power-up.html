First power-up

From a cold motor to the first turn of the shaft.

Work through this once with the shaft free. Finish Wiring first.

Before you start

Clamp or mount the motor so the shaft can spin freely and nothing can be caught by it.

Apply power

Energise the bus. The LED beside the DFU pinhole lights when power is present.

  • That LED and the window are dark: no power. Recheck the leads and the breaker.
  • The end lights are red, alternating: the controller is running but nothing is talking to it. Connect USB-C, or bring up CAN.

The full set of light patterns is on Status lights.

Configure first

Open SWYFT Link and set these before enabling:

  1. The device number (CAN ID), unique on the bus.
  2. The direction, if the shaft turns the wrong way. Orientation
  3. The stator and supply current limits for the mechanism. Current limits
Note

If the encoder has not been calibrated on this motor, run calibration from SWYFT Link over USB-C with the shaft free. It turns the shaft to learn the electrical offset and direction, then stores the result on the motor, where it survives a re-flash.

Enable and command it

The Cyclone drives on duty cycle: a signed fraction of the bus voltage from −1 to +1. Command it every loop — a setpoint older than 100 ms coasts the motor.

  1. Keep the shaft clear. Hands off the spline.
  2. Enable. On a robot, the Driver Station must be connected and enabled — the Cyclone gates output on it.
  3. Command a small duty, such as 0.1, and confirm the shaft turns.
Under construction

Closed-loop current, velocity, and position modes are defined in the API and in SWYFT Link but do not drive the motor yet. Use duty cycle for now.

What good looks like

The end lights turn solid orange when the motor is enabled and idle, solid green while it drives forward, and solid red while it drives in reverse. The shaft turns the direction you expect from the output face; if it does not, set the direction in SWYFT Link rather than negating the command. Orientation

If it does not move

What you seeWhat it means
Window darkNo power. Check the leads and breaker.
Red, alternatingNothing is talking to it. Seat USB-C, or fix CAN wiring and termination.
Blue, togetherTwo devices share a number. Change one.
Orange, enabled, no motionNo command is arriving, or the last one has gone stale. Command duty every loop.
Over-temperature patternOutput cut on heat. Let it cool; lower the stator limit. Faults
