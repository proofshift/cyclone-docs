Configuration

Set a device’s current limits, neutral mode, and other persistent settings from robot code.

A Cyclone holds its settings in on-board configuration. You change them one of two ways: the configurator, which applies a group of settings and reports whether each was accepted, or a small set of direct methods for the most common values. Both write to the device’s live configuration; neither survives a power cycle until you save.

The configurator

Call getConfigurator() to reach the settings. Build a configs object, set only the fields you want to change, and apply it. apply blocks until the device answers — call it at start-up, in robotInit(), never in a periodic loop.

Robot.java
import com.swyftrobotics.cyclone.v4.SwyftCyclone;
import com.swyftrobotics.cyclone.v4.CurrentLimitsConfigs;
import com.swyftrobotics.cyclone.v4.StatusCode;

private final SwyftCyclone intake = new SwyftCyclone(5);

@Override
public void robotInit() {
    var limits = new CurrentLimitsConfigs();
    limits.StatorCurrentLimit = 40;   // windings, amperes
    limits.SupplyCurrentLimit = 30;   // bus, amperes

    StatusCode status = intake.getConfigurator().apply(limits);
    if (!status.isOK()) {
        System.out.println("Cyclone 5 rejected a limit: " + status.describe());
    }
}

Every numeric field starts as “leave unchanged”, so an object sets only the fields you name. apply stops at the first field the device refuses and returns that StatusCode; a refused value is never silently clamped. To read the device’s current values back into an object, pass it to refresh.

Current limits

The two current limits are the settings most teams change. Set them through CurrentLimitsConfigs, above, or with the direct method setTeamLimits, which writes the temperature warning, the temperature trip, and the stator limit in one call.

Java
intake.setTeamLimits(75, 85, 40);     // warn °C, trip °C, stator A
intake.setStatorCurrentLimit(40);     // stator limit alone, 1–160 A
FieldUnitsRange
StatorCurrentLimitamperes1–160
SupplyCurrentLimitamperesup to 60

What the two limits protect, and how to size them, is on How the limits work.

Neutral mode

When no command is arriving, the Cyclone coasts. Set the neutral mode explicitly with setNeutralMode.

Java
import com.swyftrobotics.cyclone.v4.SwyftCyclone.NeutralMode;

intake.setNeutralMode(NeutralMode.COAST);

Save to keep across power

An applied setting is live immediately but is lost at the next power cycle. Call saveConfiguration once, after applying, to write the configuration to flash.

Java
intake.getConfigurator().apply(limits);
intake.saveConfiguration();   // persist across a power cycle
Note

saveConfiguration is refused while the motor is armed. Save during robotInit(), before the motor is enabled.
