First power-up

From a cold motor to the first turn of the shaft.

Work through this once with the shaft free. Finish Wiring first.

Before you start

Clamp or mount the motor so the shaft can spin freely and nothing can be caught by it.

Apply power

Energise the bus and watch the status lights under the rear window.

  • The window is dark: no power. Recheck the leads and the breaker.
  • The end lights are red, alternating: the controller is running but nothing is talking to it. Connect USB-C, or bring up CAN.

The full set of patterns is on Status lights.

Configure first

Open SWYFT Link and set these before enabling:

  1. The device number (CAN ID), unique on the bus.
  2. The direction, if the shaft turns the wrong way. Orientation
  3. The stator and supply current limits for the mechanism. Current limits

Enable and command it

The Cyclone drives on duty cycle: a signed fraction of the bus voltage, from −1 to +1. Command it over USB-C from a laptop, or over CAN from the SystemCore.

  1. Keep the shaft clear. Hands off the spline.
  2. Enable. On a robot, the Driver Station must be connected and enabled — the Cyclone gates output on it.
  3. Command a small duty, such as 0.1, and confirm the shaft turns.

What good looks like

The end lights blink orange together when a program is present but the robot is disabled, turn solid orange once it is enabled and idle, solid green while it drives forward, and solid red while it drives in reverse. The shaft turns the direction you expect from the output face; if it does not, set the direction in SWYFT Link rather than negating the command. Orientation

If it does not move

Tap the lights to play the pattern.

What you seeWhat it meansWhat to do
DarkNo powerCheck the leads and breaker.
Red, alternatingNothing is talking to itSeat USB-C, or fix CAN wiring and termination.
Blue, togetherTwo devices share a numberGive one a different number (1–62).
Orange, solidEnabled, no command arrivingSend a command — duty, velocity, position, or current.
Orange, brief offset flashesOver-temperature; output cutLet it cool; lower the stator limit. Faults
