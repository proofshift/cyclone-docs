API reference

Java methods for controlling, configuring, and monitoring a Cyclone.

Motor commands and setup

CallPurpose
new SwyftCyclone(id)Create the controller object; use a unique device number.
setDutyCycle(duty) / set(duty)Signed duty fraction, −1…+1.
setVelocity(rpm)Mechanical rotor RPM.
setPosition(rad)Rotor radians; requires configured gains.
configureMechanism(configs)Set host-side ratio and wrapping behavior.
setMechanismPosition(rotations)Command mechanism turns through that ratio.
setControl(Follower)Follow a leader through the host library.
stopFollowing()Return to direct control.
disable()Drop motion and coast.
estop() / releaseEstop()Latch / release emergency stop; enable conditions still apply.
close()Release the transport and object resources.

Duty, velocity, and position requests

Create one controller object at startup, as shown in the complete first program. In these snippets motor is that existing object. Choose one control mode and repeat its command from enabled periodic code; do not paste all three requests into the same loop.

Java
motor.setDutyCycle(0.10); // 10% output. Negative requests the other direction.
Java
motor.setVelocity(1500); // Rotor RPM; requires usable velocity gains.
Java
// Only after configuring position gains and establishing a known reference.
motor.setPosition(Math.PI / 2); // Quarter rotor turn from that reference.

Convert mechanism turns

A 5:1 ratio means five motor turns for one mechanism turn. Configure it when robot code starts. The target call belongs in periodic code, after homing and position-gain setup.

Java
MechanismConfigs mechanism = new MechanismConfigs();
mechanism.SensorToMechanismRatio = 5.0;
mechanism.ContinuousWrap = false;
motor.configureMechanism(mechanism);
// In enabled periodic code, once the reference and gains are valid:
motor.setMechanismPosition(0.25); // Quarter mechanism turn; 1.25 motor turns.

Follower and stop

Configure both motors’ limits. Here follower is a separate controller object and device 1 is the leader. Choose the alignment that matches the mechanism.

Java
follower.setControl(new Follower(1, MotorAlignmentValue.Opposed));
// Later, before sending direct commands to the follower:
follower.stopFollowing();
Java
motor.disable(); // Normal stop: remove the request and coast.
// On a separate emergency-stop event:
motor.estop();
// Release only after the cause is resolved and it is safe to re-enable.
// motor.releaseEstop();

Settings

CallImportant constraint
getConfigurator().apply(CurrentLimitsConfigs)Check StatusCode; stator ≤95 A, supply ≤40 A.
setVelocityGain(KP, KI or KD, value)Write velocity kP/kI directly; kD also accepts PID_GAIN_KD on library 0.28.0+.
getConfigurator().apply(ClosedLoopGeneralConfigs)PositionKP is supported; inspect returned status for other fields.
setVelocityDerivativeGain(kD) / getVelocityDerivativeGain()Write/read velocity kD; firmware 0.165.0+, library 0.28.0+. Range 0 to 0.001; check StatusCode. Read returns NaN if unavailable.
setNeutralMode(COAST or BRAKE)Resets on motor restart; set it again at startup.
saveConfiguration()Save supported device settings while stopped; not every overlay is persistent.

Apply configuration and check the result

Apply while stopped. The 30 A and 20 A values below illustrate the calls; select limits for your mechanism.

Java
CurrentLimitsConfigs limits = new CurrentLimitsConfigs()
    .withStatorCurrentLimit(30)
    .withSupplyCurrentLimit(20);
StatusCode result = motor.getConfigurator().apply(limits);
if (!result.isOK()) {
    motor.disable();
    System.err.println(result.describe());
}
Java
StatusCode neutral = motor.setNeutralMode(SwyftCyclone.NeutralMode.BRAKE);
if (!neutral.isOK()) System.err.println(neutral.describe());
// Set neutral mode again after restart; it is not saved to flash.

Use the supported Java gain writer for velocity. Replace kP and kI with the gains selected for your mechanism, within the accepted ranges.

Java
motor.setVelocityGain(SwyftCycloneConstants.PID_GAIN_KP, kP);
motor.setVelocityGain(SwyftCycloneConstants.PID_GAIN_KI, kI);
StatusCode derivative = motor.setVelocityDerivativeGain(0.00001); // Example only.
if (!derivative.isOK()) System.err.println(derivative.describe());
Java
ClosedLoopGeneralConfigs gains = new ClosedLoopGeneralConfigs();
gains.PositionKP = positionKp; // Your selected, positive position gain.
StatusCode result = motor.getConfigurator().apply(gains);
if (!result.isOK()) System.err.println(result.describe());
Java
// Save deliberately after checking accepted settings on a stopped motor.
// Do not put this in periodic code or save the same values on every boot.
motor.saveConfiguration();

Read measurements and faults

Measurements arrive asynchronously. A recent connection does not guarantee every cached signal is fresh. Check the relevant timestamps when a control decision depends on a measurement.

Java
double rpm = motor.getVelocityRpm();
double rotorRadians = motor.getPositionRad();
double volts = motor.getSupplyVoltage();
double supplyAmps = motor.getSupplyCurrent();
double boardCelsius = motor.getDeviceTemp();
boolean connectedRecently = motor.isAlive(0.25);
SwyftCycloneData data = motor.getLatest();
double motionReceivedAtSeconds = data.motionTimestampSec;
Java
if (motor.hasNewRefusal()) {
    System.err.println(motor.describeRefusal());
}
if (motor.hasHardFault()) {
    motor.disable();
    System.err.println(motor.getPowerStageFaultString());
}
if (motor.hasLikelyRebooted()) {
    motor.disable();
    // Invalidate your saved home/reference and re-establish it before position control.
}

Identify and set user lights

The five user LEDs use red, green, and blue values from 0 to 255. The two end status lights remain controlled by the firmware.

Java
motor.identify();           // Flash the physical motor's identify indication.
motor.setLEDs(0, 80, 255);   // Set all five user lights.
motor.setLED(1, 255, 0, 0);  // Change user LED 1 to red.
// Later, release the user-colour override:
motor.clearLEDs();

Call motor.close() when permanently disposing of the object, not after each command. See the first program for object lifetime and Status signals for measurement validity.

Unsupported operations

SurfaceCurrent behavior
setCurrent()Deprecated compatibility method; throws UnsupportedOperationException.
Slots 1 and 2Not selectable on the public gain path.
apply(Slot0Configs) gain writesReturns guidance to use setVelocityGain; not an alternative writer.
SoftwareLimitSwitchConfigsRefused by the public configurator; no claimed mechanism protection.
BrakeCurrent / BrakeMaxRpmRefused; the neutral brake is not an adjustable current regulator.
disarmDriverStationGate()Refused. The safety gate is non-disarmable.
