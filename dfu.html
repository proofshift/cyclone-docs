Firmware & DFU

Update motor firmware from SWYFT Link while the robot is disabled.

Current app and firmware

The current SystemCore download is SWYFT Link 2026.09.10-neutral1, with Cyclone firmware 0.169.1. The USB-C website offers the same firmware. This release adds separate restart interlocks for robot code and SystemCore SWYFT Link after DS disable, plus Java 0.30.0 neutral-input checking. The controller now enforces the selected temperature trip and overvoltage cutoff. The established update process and status-light meanings are unchanged.

Updating SWYFT Link does not update the motor automatically. On SystemCore, install the current IPK, then open SWYFT Link again. For USB-C, stop output and reload the website in Chrome before reconnecting. In either app, open Firmware and update each intended Cyclone, then confirm its reported version is 0.169.1. Record settings first and re-check them after the update.

Update through SystemCore

You can update over CAN with the motor installed on the robot, using SystemCore and SWYFT Link. Power the robot from a charged battery, keep Driver Station disabled, and open SWYFT Link on SystemCore. Do not update during a mechanism test.

  1. Select the Cyclone and confirm its device number. Use Identify if needed.
  2. Open Firmware. Use the offered image, or select the intended .swyftfw file.
  3. Choose Update. Keep the robot powered and the connection active while the app erases, writes, verifies, and restarts the controller.
  4. Wait for the app to confirm completion and the expected firmware version. The end of the write progress is not the end of the update.
  5. Check configuration and device identity after the restart before enabling the mechanism.

Update over USB-C

For a direct update, open SWYFT Link in Google Chrome and connect a USB-C data cable to the selected Cyclone. USB alone can power a firmware update. To run the motor afterward, connect a 12 V FRC battery through a fused or breaker-protected power connection; standalone USB-C control does not require Driver Station or CAN. Keep motor output disabled during the update, and do not disconnect while writing or waiting for the controller to reconnect.

USB-C on a robot: standalone USB-C testing does not need Driver Station. If the Cyclone is also receiving a robot signal over CAN, USB-C commands still follow Driver Station enable permission. A USB cable does not override a disabled robot.

If the update does not complete

Record the exact error and keep power stable. If the controller reconnects, check its firmware version before flashing again. Solid white lights indicate the updater state, but do not tell you whether it is progressing.

  1. Wait for SWYFT Link to report completion or a failure. Do not interrupt an update that is still running.
  2. After a reported failure, save the exact message. Reconnect using the same connection and check whether the Firmware page can reach the controller.
  3. If the app offers another update, select the intended .swyftfw image and retry with stable power. If the normal application has returned, check its version first; the write may have finished even if reconnect failed.
  4. If SWYFT Link cannot reach the controller, stop here and contact SWYFT Support. Include the error, firmware version if known, connection type, and whether the lights remain solid white.

DFU and service recovery

The DFU Button is a recovery feature. It is not used for normal CAN or USB application updates. If normal update recovery above cannot reach the controller, ask SWYFT Support for the recovery procedure and image for your hardware revision. Do not erase the entire device or use an unapproved service file. Doing so can remove the motor’s calibration and settings.
