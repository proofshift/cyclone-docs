Using SWYFT Link

Four pages: Control, Config, Health, and Firmware.

Warning

Output requires an explicit Enable. Pressing Space, hiding the tab, or closing the page stops every motor SWYFT Link is driving.

Control

Enable, then command the motor and watch it on the live graph. Duty cycle is the mode the motor runs today; current, velocity, and position appear here but do not drive yet. First power-up

  • Identify flashes the status lights white so you can tell two motors apart.
  • Re-enabling starts from zero, not the last setpoint.

Config

Set what the motor keeps:

  • Device number (CAN ID) — staged until you save; the motor reboots onto the new number.
  • Direction — which way positive turns, at the output face. Orientation
  • Current limits — stator and supply for the mechanism. Current limits
  • Thermal — the temperature warning; the trip is 85 °C.

Apply changes the running motor; Save to flash keeps the change across power. Config is locked while the output is enabled — disable first.

Health

Read active and sticky faults and clear them once the cause is gone. Watch the live gauges — temperature, current, bus voltage, speed — when the motor is hot or the bus is sagging. Faults

Firmware

The Firmware page shows the installed version and flashes updates over USB-C. The status lights go solid white during the transfer, then the motor reboots. If it will not enumerate, recover with DFU.
