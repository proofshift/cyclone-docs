Status signals

Read speed, position, current, voltage, temperature, and faults back from a Cyclone.

A Cyclone streams its state on the bus. Read one value at a time with a getter, or take a coherent snapshot of everything at once with getLatest. Read in a periodic method — the values update on their own; you do not poll the device.

Read a single value

Each getter returns the latest value for that signal. Use these when you need one or two readings.

Java
double rpm   = shooter.getVelocityRpm();      // mechanical RPM
double rad   = arm.getPositionRad();          // rotor radians, signed
double amps  = intake.getSupplyCurrent();     // bus amperes
double volts = intake.getSupplyVoltage();     // bus volts
double temp  = intake.getDeviceTemp();        // °C
GetterReturns
double getVelocityRpm()Mechanical speed, RPM.
double getPositionRad()Rotor position, signed radians.
double getDutyCycle()Present output, −1 to 1.
double getSupplyCurrent()Bus current, amperes.
double getSupplyVoltage()Bus voltage, volts.
double getDeviceTemp()Board temperature, °C.
int getI2tPercent()Thermal budget used, 0–100.
boolean hasHardFault()True while a hard fault is latched.

Read a coherent snapshot

Individual getters can read from different bus frames. When several values must agree — logging, or a state check that compares speed against current — take one snapshot with getLatest and read its fields.

Java
import com.swyftrobotics.cyclone.v4.SwyftCycloneData;

SwyftCycloneData data = shooter.getLatest();
double rpm  = data.velocityRpm;
double amps = data.supplyCurrentAmps;
double temp = data.temperatureC;
SwyftCycloneData.Mode mode = data.mode;   // DUTY, VELOCITY, POSITION, CURRENT

Check the motor is answering

isAlive is false when no frame has arrived within the age you pass — a disconnected motor, a dead bus, or a wrong device number. Gate control on it so the robot does not act on stale readings.

Java
if (!intake.isAlive(0.1)) {
    // no fresh data in 100 ms — check wiring and the device number
    intake.disable();
}

Watch thermal headroom

getI2tPercent reports how much of the thermal budget the motor has used. At 100 % the controller is in the thermal fold and trading torque for temperature. Log it during testing to size a limit that keeps a mechanism out of the fold. Power & thermal budget

Full example — telemetry to the dashboard

A subsystem periodic that publishes a motor’s state and stops it on a fault.

IntakeSubsystem.java
import com.swyftrobotics.cyclone.v4.SwyftCyclone;
import com.swyftrobotics.cyclone.v4.SwyftCycloneData;
import edu.wpi.first.wpilibj.smartdashboard.SmartDashboard;
import edu.wpi.first.wpilibj2.command.SubsystemBase;

public class IntakeSubsystem extends SubsystemBase {
    private final SwyftCyclone motor = new SwyftCyclone(5);

    @Override
    public void periodic() {
        if (!motor.isAlive(0.1)) {
            SmartDashboard.putBoolean("Intake/connected", false);
            return;
        }
        SwyftCycloneData data = motor.getLatest();
        SmartDashboard.putBoolean("Intake/connected", true);
        SmartDashboard.putNumber("Intake/rpm", data.velocityRpm);
        SmartDashboard.putNumber("Intake/amps", data.supplyCurrentAmps);
        SmartDashboard.putNumber("Intake/tempC", data.temperatureC);
        SmartDashboard.putNumber("Intake/i2t%", data.i2tPercent);

        if (motor.hasHardFault()) {
            motor.disable();   // read the fault in SWYFT Link
        }
    }
}
